## Login Issues

### Cannot Log In

**Symptoms**: Enter credentials but get error

**Solutions**:

1. **Check Email Address**
   - Verify correct email (check for typos)
   - Try alternate email if registered with multiple

2. **Reset Password**
   - Click "Forgot Password"
   - Check email for reset link
   - Link expires in 24 hours

3. **Email Verification**
   - Complete email verification first
   - Check spam folder for verification email

4. **Browser Issues**
   - Clear browser cache
   - Disable browser extensions
   - Try incognito/private mode
   - Try different browser

### Account Locked

**Symptoms**: "Account locked" message

**Causes**:
- Too many failed login attempts
- Suspicious activity detected

**Solutions**:
- Wait 30 minutes and try again
- Contact support with account details

### Two-Factor Authentication Issues

**Lost Phone (2FA)**
1. Use backup codes (saved during setup)
2. Contact support for manual verification
3. Provide identity proof

**Code Not Working**
1. Check phone time is correct
2. Wait for new code (expires in 30 seconds)
3. Resync code in authenticator app

## Booking Problems

### Cannot See Available Slots

**Symptoms**: Calendar shows no slots

**Solutions**:

1. **Check Date**
   - Slots visible 30 days in advance
   - Past dates not available

2. **Browser Issues**
   - Clear cache and reload
   - Try different browser

3. **Slot Full**
   - Try different time slot
   - Check next day

### Booking Confirmation Not Received

**Symptoms**: Payment successful but no email

**Check**:
1. Check spam/junk folder
2. Verify email address in profile
3. Check booking in "My Bookings"

**Still Missing?**
- Contact: support@srsmathaynk.org
- Provide: Transaction ID, email used

### Need to Modify Booking

**Can I change date/time?**
- Contact temple office at least 24 hours before
- Subject to availability
- May need to cancel and rebook

**Cancellation:**
1. Go to "My Bookings"
2. Select booking
3. Click "Cancel"
4. Confirmation email sent
5. Refund in 5-7 business days

### Wrong Name on Booking

**Problem**: Typo in devotee name

**Solution**:
- Contact temple office before scheduled time
- Provide correct name and booking ID
- Priests can verify with booking details

## Payment Issues

### Payment Failed

**Common Causes**:

1. **Insufficient Balance**
   - Check account balance
   - Try different payment method

2. **Bank Declined**
   - Contact bank for authorization
   - Some banks block online transactions

3. **Card Issues**
   - Verify card is activated for online use
   - Try debit card instead of credit
   - Check expiry date

4. **UPI Issues**
   - Verify UPI app has sufficient balance
   - Check UPI ID is correct
   - Try different UPI app

**Solutions**:
1. Wait 5 minutes and retry
2. Try different payment method
3. Contact bank/bank's support

### Payment Deducted But Not Confirmed

**Steps**:

1. **Note Transaction Details**
   - Transaction ID from bank/UPI
   - Amount and time

2. **Check Booking Status**
   - Log in and check "My Bookings"
   - Status might be "Pending"

3. **Wait 24 Hours**
   - Some payments take time to process
   - Check next day

4. **Contact Support**
   - Email: support@srsmathaynk.org
   - Include: Transaction ID, screenshot
   - Response within 24 hours

### Refund Not Received

**Refund Timeline**:
- UPI: 1-3 business days
- Card: 5-7 business days
- Net Banking: 5-7 business days

**If Not Received**:

1. **Verify Cancellation**
   - Check cancellation confirmation email
   - Verify cancellation fee applied

2. **Check Bank Statement**
   - Look for refund transaction
   - Check pending transactions

3. **Contact Support**
   - Provide: Booking ID, transaction ID
   - Provide: Cancellation confirmation
   - Attach bank statement if needed

### Tax Receipt Not Received

**For donations ₹500+**:

1. Check spam folder
2. Verify donation ≥ ₹500
3. Check registered email

**Still Missing**:
- Contact: accounts@srsmathaynk.org
- Provide: Donation receipt/transaction ID

## Website Errors

### Page Not Loading

**Solutions**:

1. **Check Internet Connection**
   - Try loading other websites
   - Restart router if needed

2. **Clear Browser Cache**
   - Chrome: Ctrl+Shift+Delete
   - Firefox: Ctrl+Shift+Delete
   - Safari: Cmd+Option+E

3. **Try Different Browser**
   - Chrome, Firefox, Safari, Edge
   - Update browser to latest version

4. **Check Website Status**
   - Visit status page (if available)
   - Try again later

### Stuck on Loading

**Symptoms**: Spinner keeps spinning

**Solutions**:
1. Refresh page (F5 or Ctrl+R)
2. Clear cache and reload
3. Wait 30 seconds (server might be busy)
4. Try at non-peak hours

### 500 Internal Server Error

**What it means**: Server encountered an error

**Solutions**:
1. Refresh page after 1 minute
2. Clear browser cache
3. Try again later
4. If persists, contact support

### 404 Page Not Found

**What it means**: Page removed or moved

**Solutions**:
1. Check URL for typos
2. Go to homepage and navigate from there
3. Search for content using search bar

### Session Expired

**Symptoms**: Logged out unexpectedly

**Solutions**:
1. Log in again
2. Check "Remember Me" option
3. Clear cookies if frequent

## Performance Issues

### Slow Page Loading

**Possible Causes**:
- Slow internet connection
- Too many browser tabs
- Outdated browser
- Browser extensions

**Solutions**:

1. **Check Internet**
   - Run speed test
   - Try different network

2. **Browser Optimization**
   - Clear browser cache
   - Disable unused extensions
   - Update browser

3. **Device Performance**
   - Close unnecessary tabs
   - Restart browser
   - Restart device

### Images Not Loading

**Solutions**:
1. Check internet connection
2. Allow image loading in browser settings
3. Check if site blocked in firewall
4. Try different browser

### Form Submissions Slow

**Normal Time**: 5-15 seconds

**If Taking Longer**:
1. Check internet speed
2. Don't close browser tab
3. Wait for confirmation
4. Contact if stuck >30 seconds

## Mobile Issues

### App Not Working on Phone

**Solutions**:

1. **Update App**
   - iOS: App Store → Updates
   - Android: Play Store → My Apps

2. **Reinstall App**
   - Delete app
   - Reinstall from store

3. **Clear App Data**
   - iOS: Settings → App → Clear Data
   - Android: Settings → Apps → Clear Data

### Website on Mobile Broken

**Solutions**:
1. **Force Reload**
   - Pull down to refresh
   - Or clear browser cache

2. **Check Mobile View**
   - Ensure "Desktop site" off
   - Allow responsive design

3. **Try Different Browser**
   - Chrome, Safari, Firefox
   - Update to latest version

### WhatsApp Integration Issues

**Cannot access via WhatsApp**:
1. Number might be incorrect
2. Check if WhatsApp Web works
3. Contact temple for correct number

## Error Messages

### "Please try again later"

**Meaning**: Server busy or under maintenance

**Solutions**:
1. Wait 5-10 minutes
2. Try again
3. Check status page if available

### "Session expired"

**Solutions**:
1. Log in again
2. Don't stay idle too long
3. Save work frequently

### "Invalid input"

**Solutions**:
1. Check required fields
2. Verify format (email, phone, etc.)
3. Don't use special characters

### "Connection timeout"

**Solutions**:
1. Check internet connection
2. Try again
3. Try different network

### "Service temporarily unavailable"

**Solutions**:
1. Maintenance scheduled
2. Wait and try again
3. Contact support if urgent
