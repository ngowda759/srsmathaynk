## How to Use

### Accessing Raya

1. **Look for the Chat Icon**
   - Bottom-right corner of screen
   - Purple/colored icon with chat symbol

2. **Click to Open**
   - Chat window slides up
   - Shows welcome message
   - Ready to accept queries

### Starting a Conversation

#### Step 1: Greet (Optional)
```
You: Namaste / Hello / ನಮಸ್ತೆ
Raya: 🙏 Namaste! Welcome to Sri Raghavendra Swamy Matha...
```

#### Step 2: Ask Your Question
```
You: What is the temple timing?
Raya: The temple is open:
      Morning: 5:00 AM - 1:00 PM
      Evening: 4:00 PM - 8:30 PM
```

#### Step 3: Follow Up
```
You: What about special festival timings?
Raya: On festival days, timings may extend...
```

### Best Practices

| ✅ Do | ❌ Don't |
|-------|---------|
| Be specific in questions | Ask vague questions |
| Use full sentences | Use only keywords |
| Ask one question at a time | Stack multiple questions |
| Provide context if needed | Repeat the same question |

### Example Conversations

#### Example 1: Seva Booking
```
You: I want to book Astothram for next Sunday
Raya: I'd be happy to help! Astothram costs ₹251 and takes about 45 minutes.
      To book:
      1. Go to Sevas page
      2. Select Astothram
      3. Choose your date and time slot
      4. Complete payment
      
      Would you like me to guide you through any specific step?

You: Yes, how do I select the time slot?
Raya: On the booking page, you'll see available slots marked in green.
      Select your preferred time (morning slots fill quickly, so book early!).
      Then click "Proceed to Payment" to continue.
```

#### Example 2: Festival Information
```
You: Tell me about Raghavendra Aradhana
Raya: The Raghavendra Swamy Aradhana is our most sacred festival,
      commemorating the swamiji's attaining Samadhi (spiritual liberation)
      on Margashirsha Shudda Dashami.
      
      📅 Usually falls in December-January
      🕐 10-day celebration with special pujas
      🙏 Special sevas include Mahamangalarchana
      📿 Annadanam (food offering) conducted daily
      
      Would you like details on booking sevas during Aradhana?
```

## Limitations

### What Raya Cannot Do

| Limitation | Reason | Solution |
|------------|--------|----------|
| Book sevas directly | Redirects to booking page | Guide user through process |
| Process refunds | Requires human verification | Direct to support email |
| Provide medical advice | Not trained for this | Suggest consulting priest |
| Predict exact muhurta | Astrology is complex | Provide general guidance |
| Handle complaints | Requires follow-up | Direct to temple office |

### Unavailable Information

Raya may not know:
- Real-time slot availability
- Exact priest schedules
- Personal gotra details
- Specific donation uses
- Internal temple matters

### Response Boundaries

Raya will:
- ✅ Answer factual questions about rituals
- ✅ Explain procedures
- ✅ Provide temple information
- ✅ Suggest relevant resources
- ❌ Make definitive spiritual predictions
- ❌ Provide legal/financial advice
- ❌ Share private user data
- ❌ Make unauthorized commitments

## Troubleshooting

### Common Issues

#### 1. Raya Not Responding

**Symptoms**: Chat icon appears but no response

**Solutions**:
1. Check internet connection
2. Refresh the page
3. Clear browser cache
4. Try different browser

#### 2. Incorrect Information

**Symptoms**: Response seems wrong

**Solutions**:
1. Provide feedback (👍/👎)
2. Ask to clarify in different words
3. Contact support for verification

#### 3. Language Detection Issues

**Symptoms**: Responses in wrong language

**Solutions**:
1. Start with explicit language: "Reply in Kannada"
2. Use Kannada script for better detection
3. Rephrase the question

#### 4. Repeated Responses

**Symptoms**: Same answer to different questions

**Solutions**:
1. Try rephrasing
2. Break into smaller questions
3. Contact support if persists

### Escalating Issues

If Raya cannot help:

1. **Check FAQs**: Your question might be answered
2. **Contact Support**: 
   - Email: support@srsmatha.org
   - Phone: +91-80-2844-1234
3. **Submit Feedback**: Help us improve
